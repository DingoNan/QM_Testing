## 2. Multi-Agent 流程图设计

### 2.1 布局

每个 Agent 节点用渐变圆形容器，带图标和标签，通过发光箭头线条连接。

```
    Agent 节点 (80×90)
    ┌──────────┐
    │  🧹     │  ← 图标 (白底圆)
    │          │
    │  数据清洗  │  ← 标签
    │          │
    └──────────┘
         │
    ═════╪══════  ← 发光连接线 (动态流光)
         │
    ┌──────────┐
    │  🌐     │
    │  环境识别  │
    └──────────┘
```

### 2.2 节点样式

- 背景: 渐变 (根据 Agent 类型不同颜色)
- 图标: emoji 或 SVG 图标，圆形白底
- 名称: 中文标签
- 状态: 边框发光 (running 时脉冲动画)
- 阴影: 内阴影 + 外阴影

### 2.3 连接线

- 默认: 虚线，灰色 `rgba(255,255,255,0.2)`
- Hover: 实线，渐变发光
- 动画: 流光粒子从左到右移动 (CSS @keyframes)

### 2.4 Agent 颜色映射

| Agent | 图标 | 渐变色 |
|-------|------|--------|
| 录制导入 | 📦 | #6366F1 → #818CF8 |
| 数据清洗 | 🧹 | #06B6D4 → #22D3EE |
| 环境识别 | 🌐 | #10B981 → #34D399 |
| 跨接口关联 | 🔗 | #F59E0B → #FBBF24 |
| 用例拼装 | 🧩 | #8B5CF6 → #A78BFA |
| 智能审查 | 🔍 | #EC4899 → #F472B6 |
| 试跑验证 | 🏃 | #EF4444 → #F87171 |
| 平台导出 | 📤 | #64748B → #94A3B8 |

## 3. 统计数据卡片

### 3.1 核心指标

| 指标 | 图标 | 颜色 | 数据来源 |
|------|------|------|----------|
| 录制场景数 | 📋 | Indigo | 导入的 recordings.length |
| API 接口数 | 🔗 | Cyan | stats.totalRequests |
| 管道运行次数 | ⚡ | Emerald | 历史记录计数 |
| 审查建议数 | 🔍 | Amber | candidates.length |
| 环境配置数 | 🌐 | Violet | env-config.json 计数 |

### 3.2 请求方法分布图

CSS 横向条形图：
- 每个方法一行，带 method badge
- 条形容器，填充色代表占比
- 右侧标注数量

### 3.3 环境配置概览

横向条形图显示各环境类型的配置数量：
- DEV / TEST / PRE / PROD
- 不同颜色条

## 4. 最近活动

时间线格式的活动列表：
- 时间戳 + 操作类型 + 简要描述
- 从 pipeline store 的 recordings / stats 中提取

## 6. 实现要点

- 使用纯 SVG + CSS 实现 Multi-Agent 图示
- 条形图使用 CSS width transition
- 无需外部图表库，全部原生实现
- 数据来源：pipelineStore.getState() + window.appApi
- 响应式：1024px 以下改为垂直排列
