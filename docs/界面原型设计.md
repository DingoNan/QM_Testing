# QM-Testing 界面原型设计

> 重新设计 Electron 桌面端 UI，同时支持 Web 前端运行模式  
> 设计目标：现代、简洁、信息层级清晰、可响应式

---

## 1. 设计系统

### 1.2 字体排版

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 24px | 700 | 页面标题 |
| H2 | 18px | 600 | 卡片标题 |
| H3 | 15px | 600 | 组件标题 |
| Body | 14px | 400 | 正文 |
| Small | 12px | 400 | 辅助文字 |

### 1.3 间距栅格

基于 4px 基准：`4 → 8 → 12 → 16 → 20 → 24 → 32 → 40 → 48 → 64`

### 1.4 圆角

- 小元素(按钮/标签): 6px
- 卡片/面板: 12px
- 弹窗/抽屉: 16px
- 侧边栏: 0px

## 5. Web 模式支持

### 5.1 检测策略

```javascript
// 在 app.js 启动时检测运行模式
const IS_ELECTRON = typeof window !== 'undefined' && 
                    window.process?.type === 'renderer' ||
                    typeof window.api !== 'undefined';

if (IS_ELECTRON) {
  // Electron 模式：使用 window.api (preload.js contextBridge)
} else {
  // Web 模式：使用 fetch 调用后台 REST API 或 Mock 数据
}
```

### 5.2 API 适配层

```javascript
// api-adapter.js - 统一 API 调用接口
const api = {
  // Electron 模式通过 contextBridge，Web 模式通过 fetch
  dialogOpenRecording: IS_ELECTRON
    ? () => window.api.dialogOpenRecording()
    : () => { /* Web: 使用 <input type=file> */ },

  recordingImport: IS_ELECTRON
    ? (path) => window.api.recordingImport(path)
    : (file) => { /* Web: 读取 File 对象 */ },

  pipelineStart: IS_ELECTRON
    ? (config) => window.api.pipelineStart(config)
    : (config) => fetch('/api/pipeline/start', { method:'POST', body: JSON.stringify(config) }),

  // ...
};
```

### 5.3 响应式断点

```
Desktop:  >= 1024px  — 完整侧边栏 + 内容区
Tablet:   >= 768px   — 折叠侧边栏 (图标仅显示)
Mobile:   < 768px    — 底部导航 + 全宽内容
```

## 6. 动效设计

| 元素 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 页面切换 | fadeIn + slideUp | 200ms | ease-out |
| 侧边栏 hover | background-color | 150ms | ease |
| 按钮 hover | transform: translateY(-1px) + shadow | 200ms | ease-out |
| 卡片 hover | box-shadow 增强 | 250ms | ease |
| 进度条填充 | width 过渡 | 500ms | ease-in-out |
| 弹窗出现 | scale(0.95→1) + opacity | 200ms | ease-out |
| Toast 出现 | translateX slideIn | 300ms | ease |
