# 管道后审核与导出流程实施计划

## Step 1 (B) — 管道完成后的审核查看界面

目标：管道完成后不再只显示硬编码统计，而是加载真实的 `case-save.json`，用户可以逐条查看、审核、修改用例。

### 文件修改清单

**1.1 IPC 层 — 新增读取已生成用例的通道**
- `ipc-handlers.js` — 新增 `pipeline:readResult`
  - 接收 `outDir` 参数，读取 `case-save.json`、`stats.json`、`env-config.json`
  - 返回 `{ cases, stats, envConfig }` 统一结果对象
- `preload.js` — 在 `api` 和 `appApi` 中暴露 `readPipelineResult(outDir)`

**1.2 PipelinePage 改造 — 管道完成后的结果展示**
- `PipelinePage.js` — 改造 `handleStart`：
  - 调用 `startPipeline` 成功后，调用 `readPipelineResult` 加载真实数据
  - 替换硬编码的 `{ cleaned: 12, linked: 12, cases: 12 }`
  - 根据 `getAllStats()` 计算真实的数据摘要（清洗后、关联后、用例数）
- 新增"下一步"按钮区域：
  - "审核用例" → 跳转到新的 ReviewPage
  - "重新导入" → 返回 ImportPage

**1.3 ReviewPage 创建 — 用例审核查看页面**
新建 `renderer/pages/ReviewPage.js`：
- **页面布局**：
  - 顶部：标题 + 操作按钮（折叠全部/展开全部）
  - 用例摘要统计卡片（实时计算）
  - 场景分组 → 每个场景内展示用例列表
- **用例卡片**（默认折叠，点击展开）：
  - 折叠态：`[方法] [URL路径] [状态码]` 一行显示
  - 展开态：请求头/请求体/响应体（以 JSON 格式高亮展示）、断言列表
  - 每个断言可打勾（通过/不通过）
- **操作按钮**：
  - "保存修改" — 写回 `case-save.json`
  - "导出" → 跳转 ExportPage
  - "返回管道" → 跳转 PipelinePage

**1.4 页面注册**
- `app.js` — 增加 `review` 路由到 navItems 和 renderPage
- `index.html` — 添加 ReviewPage.js 的 script 引用
- `global.css` — 新增 ReviewPage 相关样式（用例卡片、展开折叠动画、代码块样式）

## Step 2 (A) — 详情查看与导出

**2.1 ReviewPage 增强 — 编辑模式**
- 用例展开后增加"编辑"按钮，进入可编辑模式
  - 可编辑字段：用例名称、URL、方法、请求头、请求体、断言条件
  - 使用 textarea / JSON 编辑区域
  - 保存时验证 JSON 格式
- 批量操作：多选用例 → "批量导出"

**2.2 ExportPage 创建 — 导出页面**
新建 `renderer/pages/ExportPage.js`：
- 预览选中的用例列表
- 选择导出格式：JSON / CSV
- 导出按钮 → 调用 `fileExport` IPC 保存文件
- （Phase 3 增强）连接到测试平台：填写平台地址、Token、导入

## Step 3 (C) — 全流程完整实现

**3.1 Reviewer Agent 实现**
- `agents/reviewer.js` — 实现真正的审查逻辑：
  - 规则审查：硬编码检测、辅助接口识别、数组下标风险检测
  - AI 兜底：调用 `AIClient` 接口进行语义审查（可选，需配置 AI Provider）
- 输出 `candidates.json` + 修改建议

**3.2 Regression Runner Agent 实现**
- `agents/regression-runner.js` — 本地真发请求验证：
  - 按依赖顺序逐个发送请求
  - 检测依赖链断裂（token 过期、ID 不存在）
  - 输出 `regression-report.json`
- `renderer/pages/RegressionPage.js` — 试跑结果展示页面
  - 通过/失败/跳过 统计
  - 失败详情展开

**3.3 Exporter Agent + 平台对接**
- `agents/exporter.js` — 格式化输出
- `platform-connectors/metersphere.js` — MeterSphere 连接器

## 验证计划
- 每个 Step 完成后，启动 `npm run dev` 走通完整流程
- 检查 ReviewPage 能正确加载并显示 `case-save.json` 内容
- 检查修改后保存和导出功能

## 当前优先实施
按用户要求优先做：**Step 1 (B)** → **Step 2 (A)** → **Step 3 (C)**
